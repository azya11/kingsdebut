## Project overview

Kings Debut is an early-stage Go desktop chess application built with the [Fyne](https://fyne.io) GUI toolkit (v2.8.0). The codebase is currently a minimal skeleton: the UI and the chess domain logic are not yet wired together.

## Commands

- Run the app: `go run .`
- Build the Windows binary: `go build -o xo.exe .` (the tracked binary at repo root follows this naming)
- Vet: `go vet ./...`
- Tidy modules: `go mod tidy`

There are no test files in the repo yet, so `go test ./...` currently has nothing to run.

## Architecture

- **`main.go`** — Fyne app entry point. Currently a placeholder window (label + button that displays the current time); it does not yet reference the `src` package or render a chess board.
- **`src/` (package `src`)** — chess domain logic. `pieces.go` defines the `Pieces` struct (id, captured/moved flags, legal moves, position) and `Move`/`UpdateMoves` functions. This is a stub: capture handling and legal-move generation are marked as TODO and not implemented.
- **`render/`** — currently empty; intended location for board/piece rendering code that will bridge `src` domain logic with the Fyne UI.
- **`stockfish/`** — a vendored copy of the official Stockfish chess engine (full C++ source plus a prebuilt `stockfish-windows-x86-64-avx2.exe`). This directory is excluded from git via `.gitignore` and is not part of the Go build; it's present locally as the intended engine backend (e.g. for UCI-based analysis or an AI opponent), but no Go integration code exists yet.

Because `main.go` and `src/pieces.go` are not yet connected, don't assume UI actions currently drive chess logic — check both files before making changes that span the two.
